# Fullstack Auth

Aplicação full stack de autenticação desenvolvida com **TypeScript**, com foco em aprendizado de arquitetura, segurança e boas práticas de desenvolvimento.

O projeto está sendo construído de forma incremental, implementando e estudando cada etapa do processo de autenticação.

## 🚀 Tecnologias

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS

### Backend

* Node.js
* Express
* TypeScript
* Zod

### Banco de dados

* PostgreSQL
* Prisma
* Docker

### Autenticação

* Argon2
* JWT
* Access Token
* Refresh Token
* HTTP-only Cookies

### Testes e qualidade

* Vitest
* Supertest
* ESLint
* Prettier

## 🎯 Objetivo

Aprofundar conhecimentos em **desenvolvimento full stack com TypeScript**, com foco na implementação de um sistema de autenticação seguro e estruturado seguindo práticas utilizadas em aplicações profissionais.
